## 1 žingsnis: `swap<T>` — funkcijų šablonų evoliucija

**Direktorija:** `U8/01/`

#### Motyvacija

Kurso pradžioje turėjome `swap_cpp` — "elegantiška" (lyginant su C) C++ funkcija, kuri vietoj rodyklių (_pointer_) panaudoja nuorodas (_reference_), kad sukeisti jai perduodamų parametrų (argumentų) reikšmes:

```cpp
void swap_cpp(int& x, int& y) {
    int temp = x;
    x = y;
    y = temp;
}
```

Veikia su `int`. O jei reikia ir `double`? `std::string`? galų gale - `Point`?

Tiesmukiškas sprendimas: skirtingiems tipams - skirtingos, tačiau logiškai identiškos, funkcijos:

```cpp
void swapInt   (int& x,         int& y)         { int temp = x;         x = y; y = temp; }
void swapDouble(double& x,      double& y)       { double temp = x;      x = y; y = temp; }
void swapString(std::string& x, std::string& y)  { std::string temp = x; x = y; y = temp; }
...
```

Šablonų mechanizmas ir parūpina genelalizuojantį (bendrinį) sprendimą.

#### Kodas — PAVYZDYS

**main.cpp:**
```cpp
#include <iostream>
#include <string>

// --- Senas būdas: trys atskiros funkcijos ---
void swapInt(int& x, int& y) {
    int temp = x;
    x = y;
    y = temp;
}

void swapDouble(double& x, double& y) {
    double temp = x;
    x = y;
    y = temp;
}

void swapString(std::string& x, std::string& y) {
    std::string temp = x;
    x = y;
    y = temp;
}

// --- Naujas būdas: vienas šablonas ---
template<typename T>
void swap(T& x, T& y) {
    T temp = x;
    x = y;
    y = temp;
}

int main() {
    std::cout << "=== 1 žingsnis: swap<T> ===\n\n";

    // Senas būdas:
    int a = 1, b = 2;
    swapInt(a, b);
    std::cout << "swapInt:    a=" << a << " b=" << b << "\n";

    double x = 1.5, y = 2.5;
    swapDouble(x, y);
    std::cout << "swapDouble: x=" << x << " y=" << y << "\n";

    std::string s1 = "hello", s2 = "world";
    swapString(s1, s2);
    std::cout << "swapString: s1=" << s1 << " s2=" << s2 << "\n";

    std::cout << "\n";

    // Naujas būdas — vienas šablonas:
    int c = 10, d = 20;
    swap(c, d);              // T = int — kompiliatorius supranta pats
    std::cout << "swap<T> int:    c=" << c << " d=" << d << "\n";

    double p = 3.14, q = 2.71;
    swap(p, q);              // T = double
    std::cout << "swap<T> double: p=" << p << " q=" << q << "\n";

    std::string r = "foo", s = "bar";
    swap(r, s);              // T = std::string
    std::cout << "swap<T> string: r=" << r << " s=" << s << "\n";

    return 0;
}
```

#### Galima išvestis

```
=== 1 žingsnis: swap<T> ===

swapInt:    a=2 b=1
swapDouble: x=2.5 y=1.5
swapString: s1=world s2=hello

swap<T> int:    c=20 d=10
swap<T> double: p=2.71 q=3.14
swap<T> string: r=bar s=foo
```

#### Svarbu!

a) **`template<typename T>`** — deklaracija prieš funkciją. `T` yra tipo parametras — rezervuota vieta, kurią kompiliatorius užpildys konkrečiu tipu.

b) **Tipo išvedimas** — `swap(c, d)` kur `c` ir `d` yra `int`: kompiliatorius pats supranta `T = int`. Nereikia rašyti `swap<int>(c, d)` — nors galima.

c) **Kompiliatorius generuoja** — kiekvienam naudojamam tipui kompiliatorius sugeneruoja atskirą funkciją. Tai vyksta kompiliavimo metu, ne vykdymo metu.

d) **`std::swap` jau egzistuoja** — `#include <algorithm>` ir `std::swap` prieinama. Mes rašome patys, kad suprastume mechanizmą.

e) **Kodėl ne funkcijų perkrovimas (_overloading_)?** — Galėjome rašyti `swap(int&, int&)`, `swap(double&, double&)` — tai kompiliavimo meto polimorfizmas per perkrovimą. Bet perkrovimas vis tiek reikalauja kiekvieno tipo aprašo atskirai. Šablonas — viena aprašo vieta, kompiliatorius generuoja perkrovimus automatiškai. Šablonai yra perkrovimo **generalizacija**.


## 3 žingsnis: `Pair<T>` — klasės šablonas

**Direktorija:** `U8/03/`

#### Motyvacija

Funkcijų šablonai generalizavo **veiksmą** — `swap` logika nepriklausoma nuo tipo. Klasių šablonai generalizuoja **duomenų struktūrą** — `Pair<T>` laiko du elementus nepriklausomai nuo jų tipo.

Tai atspindi dvi pagrindines programavimo paradigmas: procedūrinę (funkcijos) ir objektinę (klasės). Šablonai veikia abiejose — tai ir yra jų galia.

`Pair<T>` — paprasčiausias klasės šablono pavyzdys: du tos pačios rūšies reikšmių laukai.

#### Reikalavimai

Sukurkite **`Pair.h`** failą su klasės šablonu `Pair<T>`:

- Du `private` laukai: `first` ir `second` tipo `T`
- Konstruktorius: `Pair(const T& f, const T& s)`
- Getteriai: `getFirst()` ir `getSecond()` — grąžina `const T&`
- Metodas `print()` — spausdina `(first, second)`
- Metodas `swap()` — sukeičia `first` ir `second` vietomis

c) **`swap()` metodas** — galite naudoti `std::swap` iš `<algorithm>` arba rašyti rankiniu būdu per `temp`. Abu variantai teisingi.

d) **`std::pair<T,U>` jau egzistuoja** — STL turi `std::pair` su dviem skirtingais tipo parametrais. Mūsų `Pair<T>` — supaprastinta versija su vienu tipu, mechanizmui suprasti.

## 4 žingsnis: `Stack<T>` —  steko šablonas

**Direktorija:** `U8/04/`

#### Motyvacija

Kurso pradžioje turėjome C `Stack` pavyzdį— dinaminis `char` masyvas su "rankiniu" atminties valdymu. Vėliau — C++ `Stack` su RAII principo įgyvendinimu (papildomoje medžiagoje). Dabar — `Stack<T>` šablonas: tas pats "abstraktusis" stekas, tačiau su bet kurio tipo elementų turiniu, t.y. generalizuotas (bendrinis).

#### Reikalavimai

Sukurkite **`Stack.h`** failą su klasės šablonu `Stack<T>`:

- `private` laukai: `T* data`, `int top`, `int capacity`
- Konstruktorius: `Stack(int cap = 16)` — dinamiškai alokuoja `T[cap]`
- Destruktorius: atlaisvina atmintį (`delete[] data`)
- Kopijos draudžiamos: `= delete`
- Metodai:
    - `void push(const T& value)` — deda ant viršaus
    - `T pop()` — ima nuo viršaus
    - `const T& peek() const` — "apžiūri" viršutinį nenuimdamas
    - `bool isEmpty() const`
    - `int size() const`

**Stack.h — JŪSŲ KODAS:**

```cpp

// Priminimai:

//   - destruktoriuje:  delete[] data;
```

d) **`std::stack<T>`** — C++ STL turi pilną implementaciją. Tai, ką parašėme, yra supaprastinta jo versija — mechanizmui suprasti. Realiuoe projektuose naudokite `std::stack`.

## 💡 Patarimai

1. **`template<typename T>` arba `template<class T>`** — abu sinonimai. `typename` šiuolaikiškai, `class` istoriškai. Reikšmė identiška.

2. **Šablono kodas — tik `.h`** — klasių šablonai (`Pair<T>`, `Stack<T>`) rašomi tik `.h` faile. Jei bandysite iškelti implementaciją į `.cpp` — gausite susiejimo (_linker_) klaidas.

3. **Tipo išvedimas funkcijose** — `swap(a, b)` veikia, `swap<int>(a, b)` — taip pat. Pirmas variantas paprastesnis.

4. **`pop()` iš tuščio steko** — neapibrėžtas elgesys. Prieš `pop()` visada patikrinkite `isEmpty()`.

5. **`std::stack`, `std::pair`, `std::swap`, `std::min`, `std::max`** — visi egzistuoja STL. Rašome patys ne todėl, kad STL nežinome — o todėl, kad suprastume kas yra "po kapotu".

6. **`.h` arba `.hpp`?** — klasių šablonai praktikoje dažnai talpinami `.hpp` failuose, kad vizualiai atskirti nuo C stiliaus `.h`. Tai — tik konvencija.
