    U8: Šablonai

    Savaitės: 14–15

    Svoris: 1 balas

    Terminas: 2026 gegužės 31

    Versija: v2

    🎯 Užduoties tikslas

    Suprasti funkcijų šablonus ir klasių šablonus — kaip rašyti kodą, kuris veikia su bet kuriuo tipu; pamatyti kaip STL konteineriai (vector<T>, stack<T>) naudoja tą patį mechanizmą.

    📚 Mokymosi tikslai

    Atlikę šią užduotį, mokėsite:

    • ✅ Rašyti funkcijų šablonus su template<typename T>
    • ✅ Paaiškinti tipo išvedimą (type deduction) — kada kompiliatorius supranta tipą pats
    • ✅ Rašyti klasių šablonus ir juos naudoti su skirtingais tipais
    • ✅ Pažinti standartinius vector<T>, pair<T> per šablonų mechanizmą
    • ✅ Sukurti Stack<T> — generalizuotą steko implementaciją

    1 žingsnis: swap<T> — funkcijų šablonų evoliucija

    Direktorija: U8/01/

    Motyvacija

    Kurso pradžioje turėjome swap_cpp — "elegantiška" (lyginant su C) C++ funkcija, kuri vietoj rodyklių (pointer) panaudoja nuorodas (reference), kad sukeisti jai perduodamų parametrų (argumentų) reikšmes:

    void swap_cpp(int& x, int& y) {
    int temp = x;
    x = y;
    y = temp;
}

    Veikia su int. O jei reikia ir double? std::string? galų gale - Point?

    Tiesmukiškas sprendimas: skirtingiems tipams - skirtingos, tačiau logiškai identiškos, funkcijos:

    void swapInt   (int& x,         int& y)         { int temp = x;         x = y; y = temp; }
void swapDouble(double& x,      double& y)       { double temp = x;      x = y; y = temp; }
void swapString(std::string& x, std::string& y)  { std::string temp = x; x = y; y = temp; }
...

    Šablonų mechanizmas ir parūpina genelalizuojantį (bendrinį) sprendimą.

    Kodas — PAVYZDYS

    main.cpp: 

    #include <iostream>
#include <string>

// --- Senas būdas: trys atskiros funkcijos ---
void swapInt(int& x, int& y) {
    int temp = x;
    x = y;
    y = temp;
}

void swapDouble(double& x, double& y) {
    double temp = x;
    x = y;
    y = temp;
}

void swapString(std::string& x, std::string& y) {
    std::string temp = x;
    x = y;
    y = temp;
}

// --- Naujas būdas: vienas šablonas ---
template<typename T>
void swap(T& x, T& y) {
    T temp = x;
    x = y;
    y = temp;
}

int main() {
    std::cout << "=== 1 žingsnis: swap<T> ===\n\n";

    // Senas būdas:
    int a = 1, b = 2;
    swapInt(a, b);
    std::cout << "swapInt:    a=" << a << " b=" << b << "\n";

    double x = 1.5, y = 2.5;
    swapDouble(x, y);
    std::cout << "swapDouble: x=" << x << " y=" << y << "\n";

    std::string s1 = "hello", s2 = "world";
    swapString(s1, s2);
    std::cout << "swapString: s1=" << s1 << " s2=" << s2 << "\n";

    std::cout << "\n";

    // Naujas būdas — vienas šablonas:
    int c = 10, d = 20;
    swap(c, d);              // T = int — kompiliatorius supranta pats
    std::cout << "swap<T> int:    c=" << c << " d=" << d << "\n";

    double p = 3.14, q = 2.71;
    swap(p, q);              // T = double
    std::cout << "swap<T> double: p=" << p << " q=" << q << "\n";

    std::string r = "foo", s = "bar";
    swap(r, s);              // T = std::string
    std::cout << "swap<T> string: r=" << r << " s=" << s << "\n";

    return 0;
}

    Galima išvestis

    === 1 žingsnis: swap<T> ===

swapInt:    a=2 b=1
swapDouble: x=2.5 y=1.5
swapString: s1=world s2=hello

swap<T> int:    c=20 d=10
swap<T> double: p=2.71 q=3.14
swap<T> string: r=bar s=foo

    Svarbu!

    a) template<typename T> — deklaracija prieš funkciją. T yra tipo parametras — rezervuota vieta, kurią kompiliatorius užpildys konkrečiu tipu.

    b) Tipo išvedimas — swap(c, d) kur c ir d yra int: kompiliatorius pats supranta T = int. Nereikia rašyti swap<int>(c, d) — nors galima.

    c) Kompiliatorius generuoja — kiekvienam naudojamam tipui kompiliatorius sugeneruoja atskirą funkciją. Tai vyksta kompiliavimo metu, ne vykdymo metu.

    d) std::swap jau egzistuoja — #include <algorithm> ir std::swap prieinama. Mes rašome patys, kad suprastume mechanizmą.

    e) Kodėl ne funkcijų perkrovimas (overloading)? — Galėjome rašyti swap(int&, int&), swap(double&, double&) — tai kompiliavimo meto polimorfizmas per perkrovimą. Bet perkrovimas vis tiek reikalauja kiekvieno tipo aprašo atskirai. Šablonas — viena aprašo vieta, kompiliatorius generuoja perkrovimus automatiškai. Šablonai yra perkrovimo generalizacija.

    2 žingsnis: min<T> ir max<T>

    Direktorija: U8/02/

    Motyvacija

    swap<T> pabandėte — dabar parašykite min<T> ir max<T> patys. Logika paprasta, bet reikia teisingai tvarkyti grąžinamąją reikšmę ir const nuorodas.

    Reikalavimai

    Sukurkite minmax.h failą su dviem funkcijų šablonais:

    1. min<T> — grąžina mažesnį iš dviejų
    2. max<T> — grąžina didesnį iš dviejų

    Abu turi veikti su int, double, char, std::string.

    minmax.h — JŪSŲ KODAS:

    #pragma once

// TODO: parašykite template<typename T> min funkciją
//       parametrai: const T& a, const T& b
//       grąžina: mažesnį iš dviejų (naudokite ? : operatorių arba if)

// TODO: parašykite template<typename T> max funkciją
//       parametrai: const T& a, const T& b
//       grąžina: didesnį iš dviejų

    main.cpp — JŪSŲ KODAS:

    #include <iostream>
#include <string>
#include "minmax.h"

int main() {
    std::cout << "=== 2 žingsnis: min<T> ir max<T> ===\n\n";

    // TODO: išbandykite min ir max su:
    //   int:         3 ir 7
    //   double:      3.14 ir 2.71
    //   char:        'a' ir 'z'
    //   std::string: "apple" ir "banana"

    // TODO: spausdinkite rezultatus tokiu formatu:
    //   min(3, 7) = 3
    //   max(3, 7) = 7
    //   ...

    return 0;
}

    Galima išvestis

    === 2 žingsnis: min<T> ir max<T> ===

int:    min(3, 7) = 3       max(3, 7) = 7
double: min(3.14, 2.71) = 2.71   max(3.14, 2.71) = 3.14
char:   min('a', 'z') = a   max('a', 'z') = z
string: min("apple", "banana") = apple   max("apple", "banana") = banana

    Svarbu!

    a) const T& parametrai — ne T pagal reikšmę. Šablonas turi veikti ir su dideliais objektais (std::string) — kopijavimas brangus ir nereikalingas.

    b) std::string palyginimas — < ir > su std::string veikia leksikografiškai (abėcėlės tvarka). "apple" < "banana" — true. Šablonas veikia su bet kuriuo tipu turinčiu < ir > operatorius.

    c) std::min ir std::max jau egzistuoja — #include <algorithm>. Kaip ir swap atveju — rašome patys, kad suprasti mechanizmą.

    3 žingsnis: Pair<T> — klasės šablonas

    Direktorija: U8/03/

    Motyvacija

    Funkcijų šablonai generalizavo veiksmą — swap logika nepriklausoma nuo tipo. Klasių šablonai generalizuoja duomenų struktūrą — Pair<T> laiko du elementus nepriklausomai nuo jų tipo.

    Tai atspindi dvi pagrindines programavimo paradigmas: procedūrinę (funkcijos) ir objektinę (klasės). Šablonai veikia abiejose — tai ir yra jų galia.

    Pair<T> — paprasčiausias klasės šablono pavyzdys: du tos pačios rūšies reikšmių laukai.

    Reikalavimai

    Sukurkite Pair.h failą su klasės šablonu Pair<T>:

    • Du private laukai: first ir second tipo T
    • Konstruktorius: Pair(const T& f, const T& s)
    • Getteriai: getFirst() ir getSecond() — grąžina const T&
    • Metodas print() — spausdina (first, second)
    • Metodas swap() — sukeičia first ir second vietomis

    Pair.h — JŪSŲ KODAS:

    #pragma once
#include <iostream>

// TODO: parašykite klasės šabloną Pair<T>
//
// template<typename T>
// class Pair {
//     ...
// };

    main.cpp — JŪSŲ KODAS:

    #include <iostream>
#include <string>
#include "Pair.h"

int main() {
    std::cout << "=== 3 žingsnis: Pair<T> ===\n\n";

    // TODO: sukurkite Pair<int> su reikšmėmis 3 ir 7
    //       spausdinkite, iškvieskite swap(), spausdinkite vėl

    // TODO: sukurkite Pair<std::string> su "hello" ir "world"
    //       spausdinkite, iškvieskite swap(), spausdinkite vėl

    // TODO: sukurkite Pair<double> su 3.14 ir 2.71
    //       spausdinkite getFirst() ir getSecond() atskirai

    return 0;
}

    Galima išvestis

    === 3 žingsnis: Pair<T> ===

Pair<int>:
  (3, 7)
  po swap: (7, 3)

Pair<string>:
  (hello, world)
  po swap: (world, hello)

Pair<double>:
  first=3.14  second=2.71

    Svarbu!

    a) Viskas .h faile — klasės šablonas rašomas tik .h faile. Kompiliatorius turi matyti visą šablono tekstą ten, kur Pair<int> naudojamas. Atskiras .cpp failas šablonui — dažna klaida.

    b) Tipo nurodymas privalomas — Pair<int> p(3, 7) — tipas nurodomas eksplicitiškai. Skirtingai nuo funkcijų šablonų, kur kompiliatorius gali išvesti tipą pats.

    c) swap() metodas — galite naudoti std::swap iš <algorithm> arba rašyti rankiniu būdu per temp. Abu variantai teisingi.

    d) std::pair<T,U> jau egzistuoja — STL turi std::pair su dviem skirtingais tipo parametrais. Mūsų Pair<T> — supaprastinta versija su vienu tipu, mechanizmui suprasti.

    4 žingsnis: Stack<T> — steko šablonas

    Direktorija: U8/04/

    Motyvacija

    Kurso pradžioje turėjome C Stack pavyzdį— dinaminis char masyvas su "rankiniu" atminties valdymu. Vėliau — C++ Stack su RAII principo įgyvendinimu (papildomoje medžiagoje). Dabar — Stack<T> šablonas: tas pats "abstraktusis" stekas, tačiau su bet kurio tipo elementų turiniu, t.y. generalizuotas (bendrinis).

    Reikalavimai

    Sukurkite Stack.h failą su klasės šablonu Stack<T>:

    • private laukai: T* data, int top, int capacity
    • Konstruktorius: Stack(int cap = 16) — dinamiškai alokuoja T[cap]
    • Destruktorius: atlaisvina atmintį (delete[] data)
    • Kopijos draudžiamos: = delete
    • Metodai:
      • void push(const T& value) — deda ant viršaus
      • T pop() — ima nuo viršaus
      • const T& peek() const — "apžiūri" viršutinį nenuimdamas
      • bool isEmpty() const
      • int size() const

    Stack.h — JŪSŲ KODAS:

    #pragma once

// TODO: parašykite klasės šabloną Stack<T>
//
// Priminimai:
//   - template<typename T> class Stack { ... };
//   - konstruktoriuje: data = new T[cap];
//   - destruktoriuje:  delete[] data;
//   - kopijos draudžiamos: Stack(const Stack&) = delete;
//                          Stack& operator=(const Stack&) = delete;

    main.cpp — JŪSŲ KODAS:

    #include <iostream>
#include <string>
#include "Stack.h"

int main() {
    std::cout << "=== 4 žingsnis: Stack<T> ===\n\n";

    //       pridėkite "C", "C++", "Stack<T>"
    //       išveskite pop()

    // --- Stack<double> ---
    std::cout << "\n--- Stack<double> ---\n";

    //       pridėkite kelis skaičius
    //       pademonstruokite peek() ir pop()

    === 4 žingsnis: Stack<T> ===

--- Stack<int> ---
size: 3
pop: 3

pop: 1

--- Stack<string> ---

--- Stack<double> ---

    Svarbu!

    a) Stack<T> tik .h faile — kaip ir Pair<T>. Šablono kodas turi būti matomas kompiliatoriui ten kur Stack<int> naudojamas.

    b) paprastumo dėlei šiame žingsnyje pop() ir peek() gali nekontroliuoti ar stekas tuščias, tačiau kaip papildomą pratimą rekomenduojama pridėti if (isEmpty()) throw ....

    c) Kopijos draudžiamos — Stack valdo dinamiškai alokuotą (paskirtą) atmintį. Be Rule of Three — kopija būtų pavojinga (du objektai rodytų į tą pačią atmintį). Paprasčiausias sprendimas — drausti kopiją su = delete.

    d) std::stack<T> — C++ STL turi pilną implementaciją. Tai, ką parašėme, yra supaprastinta jo versija — mechanizmui suprasti. Realiuoe projektuose naudokite std::stack.

    💡 Patarimai

    1. template<typename T> arba template<class T> — abu sinonimai. typename šiuolaikiškai, class istoriškai. Reikšmė identiška.

    2. Šablono kodas — tik .h — klasių šablonai (Pair<T>, Stack<T>) rašomi tik .h faile. Jei bandysite iškelti implementaciją į .cpp — gausite susiejimo (linker) klaidas.

    3. Tipo išvedimas funkcijose — swap(a, b) veikia, swap<int>(a, b) — taip pat. Pirmas variantas paprastesnis.

    4. pop() iš tuščio steko — neapibrėžtas elgesys. Prieš pop() visada patikrinkite isEmpty().

    5. std::stack, std::pair, std::swap, std::min, std::max — visi egzistuoja STL. Rašome patys ne todėl, kad STL nežinome — o todėl, kad suprastume kas yra "po kapotu".

    6. .h arba .hpp? — klasių šablonai praktikoje dažnai talpinami .hpp failuose, kad vizualiai atskirti nuo C stiliaus .h. Tai — tik konvencija.
