    U7: Išimčių apdorojimas

    Savaitės: 12–13(-14)

    Svoris: 1 balas (+ BONUS: 0,2)

    Terminas: 2026 gegužės 17 (pratęsta iki: 2026 gegužės 24)

    🎯 Užduoties tikslas

    Išmokti naudoti išimčių apdorojimą (throw/try/catch) kaip klaidų signalizavimo mechanizmą; suprasti stack unwinding — kaip destruktoriai iškviečiami automatiškai net kai programa "peršoka" per išimtį; dirbti su std::exception hierarchija ir kurti savas išimčių klases; susipažinti su std::unique_ptr (įvadas į išmaniąsias rodykles) kaip saugiu atminties valdymo įrankiu.

    📚 Mokymosi tikslai

    Atlikę šią užduotį, mokėsite:

    • ✅ Naudoti throw klaidų signalizavimui konstruktoriuose ir metoduose
    • ✅ Rašyti try/catch blokus ir pagauti išimtis pagal tipą
    • ✅ Paaiškinti stack unwinding — kodėl destruktoriai iškviečiami net išimties atveju
    • ✅ Skirti std::invalid_argument, std::out_of_range, std::runtime_error
    • ✅ Sukurti savą išimčių klasę paveldint iš std::exception
    • ✅ Naudoti std::unique_ptr ir std::make_unique vietoj new/delete

    📐 Užduoties formatas

    Žingsnių struktūra:

    • 6 žingsniai + BONUS
    • Žingsnis 1: Pilnas pavyzdys — apšilimas su BankAccount klase
    • Žingsniai 2–6: Vis daugiau // TODO: komentarų
    • BONUS: vector<unique_ptr<Shape>> išmaniosios rodyklės

    Kodo žymėjimai:

    • PAVYZDYS — pilnas veikiantis kodas (galite kopijuoti)
    • JŪSŲ KODAS — turite patys sukurti
    • // TODO: — komentarai nurodo, ką reikia padaryti

    Kontekstas: kur sustojome?

    U6 pabaigoje turėjome pilną Shape hierarchiją su virtual destruktoriumi:

    Shape* s = new Circle(0, 0, 5.0, "red");
s->area();       // ✅ Circle::area() — dynamic binding veikia
delete s;        // ✅ virtual destruktorius parūpina [Circle DTOR] → [Shape DTOR] —

    Bet kas nutinka jei sukuriame Circle su neprasmingu radius?

    Circle c(0, 0, -5.0, "red");   // radius < 0 — kas nutinka?
c.area();                       // grąžina neigiamą skaičių...

    Konstruktorius paklusniai sukuria neveiksnų objektą. U7 išspręs šią problemą.

    DALIS 1: "Apšilimo" pavyzdys

    1 žingsnis: throw/try/catch sintaksė

    Direktorija: U7/01/

    Motyvacija

    Prieš pereinant prie Shape hierarchijos susipažinsime su išimčių apdorojimo "mechanika" paprastesnio objekto atveju. BankAccount — klasė be paveldėjimo, be virtual, be logging'o. Tik gryna throw/try/catch sintaksė.

    Kodas — PAVYZDYS

    BankAccount.h: 

    #pragma once
#include <stdexcept>
#include <string>

class BankAccount {
private:
    std::string owner;
    double balance;

public:
    BankAccount(const std::string& owner, double initialBalance);

    void deposit(double amount);
    void withdraw(double amount);
    double getBalance() const;
    void print() const;
};

    BankAccount.cpp: 

    #include "BankAccount.h"
#include <iostream>

BankAccount::BankAccount(const std::string& owner, double initialBalance)
    : owner(owner), balance(initialBalance)
{
    if (initialBalance < 0) {
        throw std::invalid_argument(
            "Pradinis balansas negali būti neigiamas: "
            + std::to_string(initialBalance)
        );
    }
}

void BankAccount::deposit(double amount) {
    if (amount <= 0) {
        throw std::invalid_argument(
            "Įnešama suma turi būti teigiama: "
            + std::to_string(amount)
        );
    }
    balance += amount;
}

void BankAccount::withdraw(double amount) {
    if (amount <= 0) {
        throw std::invalid_argument(
            "Išimama suma turi būti teigiama: "
            + std::to_string(amount)
        );
    }
    if (amount > balance) {
        throw std::runtime_error(
            "Nepakanka lėšų: balansas=" + std::to_string(balance)
            + ", prašoma=" + std::to_string(amount)
        );
    }
    balance -= amount;
}

double BankAccount::getBalance() const { return balance; }

void BankAccount::print() const {
    std::cout << "Sąskaita [" << owner
              << "] balansas=" << balance << "\n";
}

    main.cpp: 

    #include <iostream>
#include "BankAccount.h"

int main() {
    std::cout << "=== 1 žingsnis: BankAccount su išimtimis ===\n\n";

    // --- Normalus naudojimas ---
    std::cout << "--- Normalus naudojimas ---\n";
    try {
        BankAccount acc("Jonas", 100.0);
        acc.print();

        acc.deposit(50.0);
        acc.print();

        acc.withdraw(30.0);
        acc.print();
    }
    catch (const std::exception& e) {
        std::cout << "Klaida: " << e.what() << "\n";
    }

    // --- Klaida konstruktoriuje ---
    std::cout << "\n--- Klaida konstruktoriuje ---\n";
    try {
        BankAccount bad("Petras", -50.0);   // ← throw čia
        bad.print();                         // ← NEPASIEKIAMA
    }
    catch (const std::invalid_argument& e) {
        std::cout << "Klaida: " << e.what() << "\n";
    }
    std::cout << "Programa tęsiasi po klaidos...\n";

    // --- Nepakanka lėšų ---
    std::cout << "\n--- Nepakanka lėšų ---\n";
    try {
        BankAccount acc("Ona", 20.0);
        acc.withdraw(100.0);                // ← throw čia
    }
    catch (const std::runtime_error& e) {
        std::cout << "Klaida: " << e.what() << "\n";
    }

    // --- Kelios catch šakos ---
    std::cout << "\n--- Kelios catch šakos ---\n";
    try {
        BankAccount acc("Marius", 50.0);
        acc.deposit(-10.0);                 // ← throw invalid_argument
    }
    catch (const std::invalid_argument& e) {
        std::cout << "Neteisinga reikšmė: " << e.what() << "\n";
    }
    catch (const std::runtime_error& e) {
        std::cout << "Vykdymo klaida: " << e.what() << "\n";
    }
    catch (const std::exception& e) {
        std::cout << "Kita klaida: " << e.what() << "\n";
    }

    return 0;
}

    Svarbu!

    a) throw konstruktoriuje — konstruktorius neturi grąžinamosios reikšmės. throw yra vienintelis būdas signalizuoti klaidą konstruktoriuje.

    b) Programa tęsiasi — catch blokas apdoroja klaidą ir programa tęsiasi toliau. Tai esminis skirtumas nuo "avarinio" programos užbaigimo exit() ar tiesiog programos "griūties".

    c) catch eilės tvarka — specifinės išimtys (invalid_argument) — viršuje; bendros (std::exception) — apačioje. Jei bendrą parašysite viršuje — specifinės niekada nebus pasiektos.

    d) #include <stdexcept> — būtinas std::invalid_argument, std::runtime_error ir kt. išimčių apdorojimui.

    6 žingsnis: unique_ptr — saugus atminties valdymas

    Direktorija: U7/06/

    Motyvacija

    3 žingsnyje matėme: vector<Shape*> reikalauja rankinio delete. Kiekvieną kartą. Ir jei programa nutrūksta per išimtį prieš delete — atmintis nuteka.

    P09 paskaitoje matėme šį scenarijų:

    Shape* s = new Circle(0, 0, 5.0, "red");
throw std::runtime_error("kažkas negerai");
delete s;   // ← NEPASIEKIAMA — atminties nutekėjimas!

    std::unique_ptr išsprendžia šią problemą: destruktorius iškviečiamas automatiškai — net per išimtį.

    PAVYZDYS — A dalis: unique_ptr vs new/delete

    Pažiūrėkime kaip unique_ptr veikia su vienu objektu — palyginimas su senu būdu:

    main.cpp: 

    #include <iostream>
#include <memory>      // ← būtinas unique_ptr
#include <stdexcept>
#include "Circle.h"
#include "Rectangle.h"

int main() {
    std::cout << "=== 6 žingsnis: unique_ptr ===\n\n";

    // --- A dalis: unique_ptr vs new/delete ---
    std::cout << "--- A dalis: unique_ptr pagrindai ---\n";

    // Senas būdas:
    {
        Shape* raw = new Circle(0, 0, 3.0, "red");
        raw->printInfo();
        delete raw;    // ← rankinai, privaloma!
    }

    std::cout << "\n";

    // Naujas būdas:
    {
        auto smart = std::make_unique<Circle>(0, 0, 3.0, "blue");
        //   ↑ ne new!   ↑ make_unique sukuria ir "įpakuoja"
        smart->printInfo();   // ← naudojamas kaip rodyklė
        // delete nereikia — sunaikinama automatiškai kai smart išeina iš scope
    }

    std::cout << "\n--- A dalis: baigta ---\n\n";

    3. Logging'as ir throw — jei throw įvyksta konstruktoriuje prieš logging'ą — logging'as nespausdinamas. Tai teisingas elgesys, ne klaida.

    4. make_unique sintaksė — std::make_unique<Circle>(x, y, r, color) — argumentai perduodami tiesiai į Circle konstruktorių.

    5. unique_ptr negalima kopijuoti — shapes.push_back(smart) neveiks. Naudokite shapes.push_back(std::move(smart)) arba tiesiogiai shapes.push_back(std::make_unique<Circle>(...)).
